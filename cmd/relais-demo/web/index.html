Relais cluster demo

One relay, one control plane and three separate media workers. Publish a test pattern or your camera with a readable frame counter and a synthetic tone, and see the echo.

The demo agent plays a rising ten-note scale, one count per 500 ms of consumed input. Every tenth count has a two-tone pulse. A short high chime marks each resume. Watch the count and tone phase below while moving or killing the owner.

Move and drain: gap < 100 ms. SIGKILL takeover: gap < 2 s. Both media streams must continue, with the connection staying connected, no ICE restart or renegotiation, and a continuous 60 s hold after the last event. A pending check is inconclusive.

Keep this Chrome tab and remote video visible and unobstructed. Hidden windows are invalid. Both video sources use decoded counter advances; audio gaps use total concealment samples. Starvation only downgrades a failing gap when its overlap could explain the excess above the threshold. Missing counters or inadequate audio playout is inconclusive. Raw gaps below the threshold pass regardless of the baseline floor. Run relaisDemo.runBaseline() for failure checks: too few valid baselines or a floor near the threshold can make a move or drain gap failure inconclusive. Gaps at least the threshold plus the floor max still fail; with no floor, allow one source frame interval.
